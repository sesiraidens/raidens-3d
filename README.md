## Sobre

Modelos 3D projetados para impressao com foco em durabilidade, facilidade de montagem e substituicao rapida. Chassis, suportes, engrenagens e acessorios.

---

## Pecas

| Categoria | Pecas |
|---|---|
| chassis/ | Chassis principal, tampa superior |
| suportes/ | Ultrassonico, camera, bateria, Arduino, L298N |
| engrenagens/ | 20 dentes, 40 dentes |
| estrutural/ | Bracket motor, suportes de roda |
| acessorios/ | Gancho resgate, bandeira, suporte sensores |

---

## Material Recomendado

- PETG para pecas estruturais
- PLA para pecas leves e acessorios
